Design rules, made observable.

I took Gooseworks' agent-facing design specs and built a small interface for seeing, compiling, and testing them.

Open Speclint → See the source repo
01

Observation

Gooseworks writes its design rules as markdown, so agents can build consistent ads without a person reviewing every pull request. That's in the job posting for their Design Engineer role, almost word for word: consistency is enforced by what's written down for the agents, not by a human reviewing the work.

02

Evidence

They open-sourced the whole system. gooseworks-ai/goose-skills on GitHub has real published style specs and a real QA file for agent-generated ads, with specific, numeric rules already written down.

  • STYLE_PRESETS.md · real color, type, and mood specs for named styles like Bold Signal and Dark Botanical
  • verifier.md · the actual check an agent's ad output has to pass, including "legible at 256px thumbnail"
03

Hypothesis

An agent reads those files and follows them exactly. A person can't check the same rule at all, not without asking an agent to render something first, then eyeballing it. The rule and the reader are built for each other. There's no version built for a person yet.

04

What I built

Speclint. Pick one of those real style specs, watch it drive a live ad component. Pick a broken version of that ad, watch the same rule that grades the agent's work catch it, with the exact number and the exact element flagged.

STYLE_PRESETS.md → live component → pass / fail, with receipts
05

How it works

Three screens. A catalog that renders the specs as real swatches and type, not hex codes on a page. A compile step where one ad component re-skins entirely from CSS custom properties, no markup changes. A lint step where contrast, palette distance, thumbnail legibility, and safe-margin overflow are computed live against whatever's actually rendered, not scripted.

Legible at 256px thumbnail Fail 4.8px at thumbnail size, needs ≥ 6px
06

What makes it real

The 256px number isn't mine, it's theirs, pulled straight from verifier.md. Their own published presets, Bold Signal and Dark Botanical, pass every check on a clean render. Only the versions I broke on purpose fail, and only where I broke them.

You've already solved the hard half of this: teaching agents to follow design rules exactly. I got curious what the other half looks like.
07

What I learned

Their design system is already good. It's just built for one reader so far. Checking it as a human meant building the reader myself.

08

What I'd explore next

The verifier also does vision checks, layout match, no overlapping text, that need a model, not a formula. That's the harder layer, and the one I didn't build.

Speclint is live, functional, and built entirely from Gooseworks' own public rules. No login, nothing scripted.
